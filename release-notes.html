Release Notes

Latest updates and improvements to Antigravity Play

Version 1.2.0 — "Information Expansion"

This release focuses on expanding the platform's information architecture. We have added comprehensive utility pages, system status pages, admin logging capabilities, and a fully functional blog. The footer has been redesigned with better information hierarchy for improved accessibility and SEO.

New Pages: About, Contact, FAQ, Help Centre, Community Guidelines, DMCA, Copyright, Cookie Policy, Advertise, Press, Blog, Changelog, Release Notes, Announcements, Tutorial, Feedback, Report Bug, Feature Request, Sitemap, Status, 404, 403, 500, Maintenance, Offline, Search Empty, No Internet, Activity Logs, Login Logs, Error Logs

Improvements: Footer information architecture redesigned, SEO optimization with descriptive meta tags, consistent page-enter animations across all new pages.

Version 1.1.0 — "Polishing Pass"

Focused on user experience improvements and bug fixes. Added legal pages (Privacy Policy, Terms of Use), forgot password flow, and enhanced the theme system. Fixed page movement issues after refresh and improved mobile responsiveness.

Version 1.0.0 — "Initial Launch"

The first release of Antigravity Play. Core video browsing and watching experience with custom player, admin panel, and full theme support.
